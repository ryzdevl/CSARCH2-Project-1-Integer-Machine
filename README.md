## Machine 1: Integer Machine
Process: Integer arithmetic and conversion.
1. Convert decimal to unsigned and signed binary <br>
a. Input: A decimal number. <br>
b. Input: Data size (ranging from 2 bits to 64 bits and beyond). <br>
c. Output: Both unsigned and signed binary representations (must include error checking for out-of-bounds
values). <br>
2. Perform multiplication (sequential circuit binary multiplier), and division (non-restoring) <br>
a. Input: Operands in either decimal (which must be converted to binary internally) or binary format. <br>
b. Input: Data size (in bits). <br>
c. Output: The step-by-step solution and the final result <br>
